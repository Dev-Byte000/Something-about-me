# Hemendra's Portfolio Website

A personal portfolio website showcasing my journey as a BCA student, my skills in programming, video editing, and creative projects.  
This site highlights my background, projects, and ways to connect with me.

---

## 🚀 Features
- **Home Page**: Introduction and portfolio entry point.
- **About Page**: Details about my journey, skills, and interests.
- **Projects Page**: Showcases key projects in C++, Java, web development, and editing.
- **Contact Page**: Provides links to email, LinkedIn, and GitHub.
- **Responsive Design**: Styled with CSS for clean layout and hover effects.
- **Dynamic Typing Animation**: Implemented using JavaScript (`Typed.js`).
